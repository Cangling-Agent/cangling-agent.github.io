SimCRAFT: Distilling Remote Sensing Agents via Synthetic Trajectories and Contextual Retrieval-Augmented Fine-Tuning

Teach a compact language model to turn a remote sensing request into a reliable sequence of tool calls, using synthetic experience and retrieved procedural knowledge.

01 / The idea

Small models.
Structured experience.

Remote sensing analysis often requires a chain of specialized operations: finding imagery, preprocessing it, selecting compatible tools, and passing the correct outputs from one step to the next. Large general-purpose language models can orchestrate these workflows, but their deployment can be costly.

SimCRAFT brings this planning ability to compact language models in two phases. A multi-agent synthesis pipeline creates constraint-validated tool-use trajectories. Contextual Retrieval-Augmented Fine-Tuning (CRAFT) then trains a model to adapt retrieved Standard Operating Procedures (SOPs) to a new request, including when the retrieved context contains irrelevant examples or incorrect parameters.

The result is a 7B-scale planner that improves tool selection and argument accuracy while reducing hallucinated tools and paths. We evaluate it on SimRS-14k and two additional benchmarks, KnowFlow-Bench and ThinkGeo.

02 / How it works

Synthesize experience. Learn to adapt.

Two phases, one compact planner.

Phase I

Multi-agent data synthesis

Starting from 162 expert seed tasks, the pipeline simulates both novice users who need clarification and experts who provide complete requests. Planning, execution, reflection, and summary agents generate multi-step tool-use trajectories over 36 remote sensing tools.

A Mock Execution Engine checks argument schemas, inter-tool dependencies, and sensor/tool compatibility. Recoverable error injection adds opportunities to learn correction and replanning.

Phase II

Contextual retrieval-augmented fine-tuning

A frozen retriever supplies relevant SOPs from a Procedural Knowledge Base. During training, irrelevant context injection and parameter mutation perturb these references while the target trajectory remains correct.

This teaches the model to transfer useful workflow structure and recompute query-specific details. At inference, it retrieves SOPs without training-time perturbations and generates the tool-call sequence.

03 / SimRS-14k

From seed tasks
to tool-use trajectories.

The synthesis pipeline retains 14,003 trajectories from 16,200 candidates after constraint validation, a 13.6% rejection rate. The experimental split uses 13,503 training trajectories and 500 held-out test trajectories.

Four remote sensing experts inspect a stratified sample of 2,800 trajectories; 2,787 pass the stated workflow and query-answering checks. The 13 flagged examples remain as low-rate residual noise.

04 / Evaluation

Competitive planning at 7B scale.

All scores below are percentages.

On the SimRS-14k test split, SimCRAFT-Qwen2.5-7B reaches 83.2% planning success, compared with 46.2% for the base Qwen-2.5-7B-Instruct model. The 95% bootstrap confidence interval is [80.6, 85.7]. Larger specialized RS agents retain a planning-success advantage, while SimCRAFT improves tool selection and argument accuracy.
